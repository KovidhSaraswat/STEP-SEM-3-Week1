# STEP SEM 3 - Week 1 Java Solutions

This repository contains Java program implementations for the Week 1 lab and arcade practice problems.

## 📂 Included Problems & Files

1. **Rock-Paper-Scissors Game** (`RockPaperScissors.java`)
   * Simulates a 5-round match against the computer with a formatted summary table and win percentage statistics.

2. **Palindrome Checker** (`PalindromeChecker.java`)
   * Implements and verifies text palindromes using 3 independent techniques: Iterative, Recursive, and Array Reversal.

3. **BMI Calculator for a Team** (`BMICalculator.java`)
   * Calculates BMI and determines health status for a team of 10 people, outputting a structured wellness report table.

4. **First Non-Repeating Character** (`FirstNonRepeatingChar.java`)
   * Scans an input string to find and output the first character with a frequency of 1.

5. **Reverse Customer Name** (`ReverseCustomerName.java`)
   * Reverses a string using character array manipulation while preserving the original name variable.
